# HRA_code
WOS包含两个部分，一个是每层层级token用两个，一前一后的，是用后缀2token表示；另一个部分是只用一个层级token放在每层最前面的，正常后缀没有2token。prepare_data.py是学生教师训练之前对数据集进行预处理，用来建立全局唯一的label2id映射。studen和teacher的train以及test是用来对学生教师做训练以及测试的代码，distill和distill_test是用来进行蒸馏的脚本。extract_wos_teacher.py是用来提取教师模型特征的脚本。analyze是对单token蒸馏的学生模型做case分析的脚本，WOS_teacher_vs_full_hier0001_case_analysis.xlsx是分析之后的结果。

nyt和bgc是一样的结构，prepare_data.py是学生教师训练之前对数据集进行预处理，用来建立全局唯一的label2id映射。studen和teacher的train以及test是用来对学生教师做训练以及测试的代码。extract_nyt/bgc_teacher.py是用来提取教师模型特征的脚本。distill是hier全层级蒸馏，distill_masked是hier的mask，也就是只蒸馏有label的层级的版本。这两个蒸馏的脚本可以直接用一个distill_test进行测试

这三个数据集具体运行顺序是先运行prepare_data.py对数据集进行预处理，之后运行教师和学生的训练以及测试脚本，然后运行extract_wos_teacher.py提取教师特征做离线保存，最后运行distill蒸馏，蒸馏后进行测试。
